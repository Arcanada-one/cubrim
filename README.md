# Cubrim

Cubrim — проект сжатия без потерь, адресного представления, хранения и передачи данных. Продуктовая семья: **Cubrim Архиватор**, **Cubrim Адресатор**, **Cubrim Web**.

## Начать работу

**[Дорожная карта развития](ROADMAP.md)** — основной план проекта. Первый приоритет: ускорить архиватор и распаковку, снизить потребление памяти и облегчить поставку.

## Сайт и разработка

Публичная дорожная карта: [русский](https://cubrim.com/ru/roadmap) · [English](https://cubrim.com/en/roadmap).
Исходники сайта находятся в отдельном репозитории [cubrim-site](https://github.com/Arcanada-one/cubrim-site).

Перед реализацией прочитайте `AGENTS.md` и правила выбранного компонента. Не заменяйте текущие измерения показателями исторической презентации и не объявляйте план выполненным без принятой ревизии и проверок. Условия использования кода определяет [LICENSE](LICENSE).
