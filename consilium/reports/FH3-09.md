# FH3-09 — Image-specific SSE/APM цепь над 2D-соседским контекстом остатков MED16 (error-feedback bias-cancellation) — target: image (защита/расширение x-ray/mr/ptt5, дёшево)

**Волна:** WAVE 3 (2026-07-22, Fable 5). **Статус:** PROPOSED, не запускалось.

## Механизм

CALIC-класс делает ключевую вещь, которой в нашем shipped MED16-пути НЕТ: **контекст-зависимая коррекция систематического смещения (bias) предиктора через error-feedback** — предиктор запоминает средний остаток В КАЖДОМ контексте (текстура/градиент соседей) и вычитает его перед кодированием. Cubrim имеет SSE/APM-цепь в MODE_CM, но она общая (байтовая), не заточенная под 2D-структуру изображения.

Перенос: добавить в image-путь **image-specific APM-звено**, где контекст = квантованная 2D-активность соседей (|N−W|, |NW−N|, битовая плоскость), а корректируемая величина — остаток MED16. APM обучает уточнённое распределение остатка под каждый контекст активности → снимает контекст-зависимый bias, который единый предиктор оставляет. Целочисленно, wire=0 (адаптивно), fail-closed, за competitive-min.

## Чем берёт лидера

Наш MED16 (H-60/H-63) — ЧИСТЫЙ предиктор без контекстной bias-коррекции; остаток идёт в общий CM. CALIC/GAP бьют MED именно error-feedback-коррекцией по контексту активности (документировано: «предиктор корректирует себя, обучаясь на прошлых ошибках в данном контексте»). Добавить это как APM-звено ПОВЕРХ MED16 — самый дешёвый способ приблизиться к CALIC-качеству без замены предиктора. Расширяет тонкий image-margin −4.6% при малой стоимости.

## Научный источник (родословная)

- **CALIC** (Wu & Memon): GAP-предиктор + контекст-селекция + **error-feedback bias-cancellation** + контекст-моделирование остатков — четыре компонента; bias-cancellation — тот, что MED16 не имеет.
- **SSE/APM (Secondary Symbol Estimation / Adaptive Probability Map)** — механизм paq/zpaq для уточнения оценки по вторичному контексту; здесь применён с 2D-image-контекстом.
- Gradient-edge-detection предикторы (ResearchGate) — генеалогия контекст-активности как переменной коррекции.

## Оценка выигрыша (с чарджем)

- x-ray/mr: **−1…−4% self** поверх MED16 (грубо; bias-cancellation даёт классический CALIC-vs-MED зазор ~1–4% на континуальных grayscale). ptt5 (bilevel) — как частный случай (контекст = биты соседей), доборно.
- Чардж: адаптивно, **wire=0** (APM-таблицы обучаются онлайн из нуля). Стоимость — малая (APM-звено = таблица оценок по квантованному контексту + интерполяция); декодер ≈ той же цены, ×1.05–1.15. Это САМАЯ дешёвая image-карточка волны по стоимости реализации.

## Cheap probe (GO/NO-GO)

1. **Часы, Python:** на остатках MED16 x-ray/mr посчитать СРЕДНИЙ остаток по квантованным контекстам активности (|N−W|, |NW−N|). Если средний остаток заметно ≠0 и зависит от контекста → есть систематический bias, который APM снимет, GO. Если остаток уже ≈нулевого среднего во всех контекстах → MED16 несмещён, bias-cancellation не даст, NO-GO.
2. End-to-end: MED16 + контекст-bias-вычитание + адаптивный кодер остатка vs чистый MED16 — прямая дельта.

## Риск / стоимость

- 1–3 дня (APM-звено — малый изолированный компонент в image-пути). Арх-риск НИЗКИЙ (аддитивно, competitive-min ≥0). RT-риск низкий, скорость декодера почти не страдает. Приоритет: **высокий по ROI:стоимость в image-ветке** — дешевле FH3-01/02, probe-1 (bias-замер) — минуты/часы; хороший быстрый инкремент к тонкому image-margin ещё до дорогих MRP/bit-plane.

## Отличие от H-* / FH-* / FH2-*

- **H-60/H-63 (MED16)** — предиктор БЕЗ bias-коррекции; FH3-09 добавляет контекст-зависимую error-feedback-коррекцию (то, чем CALIC бьёт MED) как отдельное APM-звено.
- **FH-14 (CALIC-класс контекст-моделирование остатков)** — FH-14 про КОНТЕКСТ-БАКЕТЫ для энтропийного кодирования остатка; FH3-09 конкретно про **bias-cancellation** (вычитание среднего остатка по контексту ДО кодирования) + SSE/APM-топологию. Частично пересекается с CALIC-генеалогией, но механизм — коррекция предсказания, не бакетизация энтропии; можно рассматривать FH3-09 как дешёвую, изолированную реализацию именно bias-компонента CALIC (одного из четырёх), тогда как FH-14 брала контекст-моделирование остатков (другой компонент). Если FH-14 пойдёт — FH3-09 меряется как его bias-под-часть.
- **FH2-09 (MA-tree)** — обучаемая структура контекстов; FH3-09 — фиксированный SSE над готовым 2D-контекстом (дешевле, слабее, но почти бесплатно). Ортогонально предиктору (FH3-01 MRP) и разрезу плоскостей (FH3-02).
