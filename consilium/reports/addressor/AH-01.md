## Каноническая формулировка (если X → Y на Z, потому что M)

Если зафиксировать versioned-immutable глобальный словарь как секцию матрицы и передавать dict_id+поток со словарём, то net-байты на мелких структурированных файлах (<128 KiB) упадут vs локальный zstd, потому что малый файл не успевает выучить собственную статистику.

## Поля карточки

- **Физическая модель / каталог:** готовый контекст с первого байта; амортизация однократной доставки словаря
- **Класс данных (Z):** small structured files (JSON/HTML/logs/configs)
- **Address target:** не применим (схема не ссылочная / инфра-статья)
- **Predicted lever (предсказание, НЕ измерение):** >=25% на smalls (предсказание), ->0 на >=4 MiB
- **Ceiling-категория:** `shared-context`
- **Falsification test:** корпус мелких файлов: выигрыш <25% или словарь не амортизируется -> NO-GO
- **measured_result:** null — измерений не было, статус OPEN честен
- **code_ref:** null — кода ещё нет
- **Source:** epic-brief C + zstd --train literature

## total_cost = address + metadata + residual + amortized(matrix/catalog/distribution/sync/integrity)

address: 8 B dict_id · metadata: zstd-frame header · residual: ВЕСЬ сжатый поток (схема не ссылочная) · amortized: dict_size/N_files устройства + однократная доставка словаря на устройство.

## Честный потолок / граница no-win

Не выигрывает: файлы ≥4 MiB (внутренняя статистика доминирует), уникальное высокоэнтропийное, данные вне домена словаря.

## Авторский разбор (из синтез-отчёта волны 1)

### AH-01 · Матрица-как-словарь (shared dictionary) — `shared-context`
**Если** зафиксировать versioned-immutable глобальный словарь (обученный zstd `--train`-методом на репрезентативном мультидоменном корпусе; секция матрицы «общая статистика мира») и передавать `dict_id (8 B) + поток, сжатый со словарём`, **то** передаваемые байты на классе **мелких структурированных файлов (<128 KiB: JSON/HTML/логи/конфиги)** снизятся относительно локального zstd без словаря, **потому что** малый файл не успевает выучить собственную статистику, а словарь даёт контекст с первого байта.
- Физическая модель: неизменяемый блоб словаря (МиБ—ГиБ), доставлен заранее, амортизирован по всем файлам устройства.
- Address target: неприменим (это не ссылочная схема; residual = весь сжатый поток).
- Predicted lever: заметный на smalls; **предсказание** ≥25% на классе Z, →0 на файлах ≥4 MiB (внутренняя статистика доминирует).
- Falsification: корпус реальных мелких файлов; если выигрыш <25% на smalls ИЛИ амортизация словаря не окупается при реалистичном числе файлов на устройстве — NO-GO.
- Честный потолок: словарь покрывает «головы» распределения; НЕ даёт 16–64 B ссылок; это baseline, который любые фрагментные схемы (AH-07) обязаны бить.
- total_cost: address 8 B + metadata (frame) + residual (весь поток) + amortized(dict_size/N_files_на_устройстве; distribution — однократная доставка словаря).

## Verdict — NO-GO (2026-07-14, W1-fragments-v1b-fair, MEASURED)

Реальный zstd-словарь 110 КиБ (train/test по чётности хэша, 61 704/59 936 файлов класса Z): выигрыш **2.94 пп абсолютных / 9.95% относительных** против плоского zstd-3 — далеко от пре-регистрированного бара ≥25%. **NO-GO.** Рычаг существует, но величина съедена силой самого локального кодека (семейство Gotcha #11). Словарь остаётся baseline-конкурентом для любых фрагментных схем.
