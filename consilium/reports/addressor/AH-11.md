## total_cost = address + metadata + residual + amortized(matrix/catalog/distribution/sync/integrity)

это агрегатор total_cost всего трека: B(N)=Σsavings(N) − M_size − C_catalog_sync(N) − C_residual_overhead(N); порог N* = корень B.

## Честный потолок / граница no-win

Не выигрывает: классы, где N* превышает реалистичный размер флота (уникальный персональный контент: N*→∞) — канонизируются как «вне рынка адресатора».

## Авторский разбор (из синтез-отчёта волны 1)

### AH-11 · Порог окупаемости N* (break-even) — `infra-cost`
**Если** формализовать B(N) = Σsavings(N) − M_size − C_catalog_sync(N) − C_residual_overhead(N) по N файлов/устройств, **то** для фиксированной матрицы существует измеримый порог N*, причём на классе **enterprise-backup/однородных флотов** N* достигается при реалистичных размерах флота, а на классе **уникального персонального контента (свои фото/видео)** N*→∞, **потому что** savings пропорциональны кросс-девайсной повторности, которая у уникального контента ~0.
- Falsification: посчитать N* на 2–3 реальных смесях; классы с N* больше реалистичного флота — канонизировать как «вне рынка адресатора».
- Продукт гипотезы: формула и таблица N* по классам — измеритель честности всего трека.

## Verdict — GO (2026-07-14, W1-nstar-v1, measured parameters)

B(N) = c·d·(N−1) − 2·k_cat·u·N на измеренных входах (c=0.1621 кросс-чанк, d=4.31 ГБ/устройство, u=2.46 ГБ unique, k_cat=0.00419): **N\*=2** для office/infra-класса (B(1)=−0.019 → B(2)=+0.613 → B(100)=+62.6 ГиБ); для уникального персонального класса c~0 → N\*→∞. Оба предсказания подтверждены. **GO** — формула и таблица приняты измерителем честности трека.
