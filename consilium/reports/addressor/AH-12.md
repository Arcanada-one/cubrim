## Каноническая формулировка (если X → Y на Z, потому что M)

Если матрицу заморозить (immutable v1 по канону), то hit-rate на свежем контенте будет монотонно деградировать с измеримой скоростью d(hit)/dt, потому что распределение реальных данных нестационарно.

## Поля карточки

- **Физическая модель / каталог:** нестационарность данных vs снимок прошлого
- **Класс данных (Z):** новости, обновляемый софт, новые форматы
- **Address target:** не применим (схема не ссылочная / инфра-статья)
- **Predicted lever (предсказание, НЕ измерение):** полураспад словарных секций быстрее чанковых (предсказание, без чисел)
- **Ceiling-категория:** `infra-cost`
- **Falsification test:** hit-rate(t) на датированных снапшотах корпуса
- **measured_result:** null — измерений не было, статус OPEN честен
- **code_ref:** null — кода ещё нет
- **Source:** canon 'набор неизменяемых блоков' + нестационарность

## total_cost = address + metadata + residual + amortized(matrix/catalog/distribution/sync/integrity)

стоимость каждой новой версии матрицы = distribution+sync на каждое устройство; выигрыш = восстановленный hit-rate; чистый эффект = разница.

## Честный потолок / граница no-win

Не выигрывает: быстро дрейфующие классы при дорогой дистрибуции версий — замороженная матрица там деградирует быстрее, чем окупается обновление.

## Авторский разбор (из синтез-отчёта волны 1)

### AH-12 · Деградация замороженной матрицы (drift) — `infra-cost`
**Если** матрицу заморозить (immutable v1 — как требует канон «набор неизменяемых блоков»), **то** метрика hit-rate на классе **свежего контента (новости, обновляемый софт, новые форматы)** будет монотонно деградировать со временем с измеримой скоростью d(hit)/dt, **потому что** распределение реальных данных нестационарно, а замороженная матрица — снимок прошлого.
- Predicted: полураспад полезности словарных секций — быстрее, чанковых — медленнее (предсказание, без чисел).
- Falsification: hit-rate(t) на датированных снапшотах корпуса; результат определяет политику версий, а КАЖДАЯ новая версия матрицы — снова distribution-cost в total_cost.

Дрейф замороженной матрицы измерен на реальных датированных git-снапшотах KB (read-only cat-file, без checkout): hit-масса **100 → 98.58 → 97.37 → 96.86%** за 2.5 месяца, **d(hit)/dt ≈ −1.3 пп/мес**, монотонно. Ограничения окна честно зафиксированы (история глубже 2026-05-01 недоступна — экосистемный git-reset 2026-05-11; один класс; только чанк-секции). **GO.**
