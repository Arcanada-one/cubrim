## Каноническая формулировка (если X → Y на Z, потому что M)

Если адрес указывает ближайший фрагмент матрицы и передаётся только дельта, то net-байты на версионированных данных упадут до address+delta << full, потому что соседние версии близки по содержимому.

## Поля карточки

- **Физическая модель / каталог:** малые дельты между версиями; rolling-hash поиск ближайшего
- **Класс данных (Z):** код, документы, бэкап-цепочки
- **Address target:** 32 B
- **Predicted lever (предсказание, НЕ измерение):** крупный (rsync-практика, внешняя ссылка)
- **Ceiling-категория:** `near-match-delta`
- **Falsification test:** charged: address+delta+доля каталога vs локальный zstd-19 со словарём на multiversion; не бьёт -> NO-GO
- **measured_result:** null — измерений не было, статус OPEN честен
- **code_ref:** null — кода ещё нет
- **Source:** rsync/bsdiff literature

## total_cost = address + metadata + residual + amortized(matrix/catalog/distribution/sync/integrity)

address: 32 B ближайшего фрагмента · metadata: инструкции применения дельты · residual: сама дельта · amortized: rolling-hash индекс по ВСЕЙ матрице — тяжёлая каталожная статья.

## Честный потолок / граница no-win

Не выигрывает: пережатые/перешифрованные версии (дельта = весь файл → класс AH-16); и когда локальный zstd-19 со словарём даёт то же без глобального индекса.

## Авторский разбор (из синтез-отчёта волны 1)

### AH-15 · Near-match адрес + дельта (rsync-родня) — `near-match-delta`
**Если** адрес указывает ближайший фрагмент матрицы, а передаётся только дельта (rolling-hash/bsdiff-механика), **то** метрика net-байт на классе **версионированных данных (код, документы, бэкап-цепочки)** упадёт до address + delta ≪ full, **потому что** соседние версии близки по содержимому и дельта мала.
- Predicted lever: крупный (rsync-практика — внешняя ссылка, не измерение).
- Falsification: charged-замер на multiversion: address + delta + доля каталога против ЛОКАЛЬНОГО zstd -19 со словарём; не бьёт — NO-GO. Отдельно: rolling-hash-индекс по ВСЕЙ матрице — тяжёлая статья каталога (в total_cost).
- Честный потолок: умирает на пережатых/перешифрованных версиях (дельта = весь файл, класс уходит в AH-16).
