# FH3-01 — MRP (Minimum-Rate Predictors): оптимизируемый набор линейных предикторов с передаваемыми коэффициентами + контекстная кластеризация остатков — target: image (x-ray/mr; континуальные grayscale), удержание/расширение запаса #1

**Волна:** WAVE 3 (2026-07-22, Fable 5). **Статус:** PROPOSED, не запускалось.

## Механизм

MRP (Matsuda et al., Tokyo Univ. of Science; один из признанных SOTA lossless-grayscale) заменяет ОДИН фиксированный предиктор (MED/GAP) на **набор из K линейных предикторов больших опор (8–20 отсчётов), коэффициенты которых кодер итеративно подгоняет ПОД КОНКРЕТНОЕ изображение так, чтобы минимизировать не MSE, а суммарную длину кода** (rate). Пиксели кластеризуются по локальному контексту (активность градиента) в M групп, каждой назначается свой предиктор из набора; остатки кодируются контекст-адаптивной арифметикой с бинам по дисперсии. Коэффициенты + карта назначения предикторов передаются в заголовке (десятки–сотни байт — **полностью чарджится**).

Перенос в Cubrim image-профиль: после детекции grayscale-геометрии — второй проход `optimize(predictors, assignment)` минимизирует Σ−log2 p(residual); остатки идут в существующий CM/rANS. Всё целочисленно (fixed-point коэффициенты, round-to-nearest), детерминированно, fail-closed, за competitive-min.

## Чем берёт лидера

Наш shipped image-путь = MED16 (H-60/H-63) — ОДИН фиксированный предиктор. ppmd 0.4545 на x-ray, мы 0.311949 агрегат по типу с margin всего −4.6%. MED оптимален для «медианного» градиента, но проигрывает на текстуре/анизотропии рентгена. MRP **подгоняет форму предиктора под статистику именно этого снимка** и минимизирует rate напрямую → лит. MRP стабильно бьёт CALIC/JPEG-LS/JPEG2000 на континуальных grayscale на 3–8%, а на медицинских объёмах (3-D-MRP) ещё больше. Это прямой инкремент поверх MED16 там, где image-margin тоньше всего.

## Научный источник (свежесть/родословная)

- **MRP** — Matsuda et al., «Design and evaluation of minimum-rate predictors for lossless image coding» (IEEE); референс-реализация 8-bpp PGM на сайте лаборатории. **3-D-MRP** — «Lossless Compression of Medical Images Using 3-D Predictors» (IEEE TMI, 2017) — прямое применение к CT/MRI, класс наших mr/x-ray. Свежесть подтверждена продолжающимися расширениями: 4-D MRP для light fields (2022), rate-complexity trade-off (EUSIPCO 2019). Класс жив и остаётся SOTA-бейзлайном в DCC-литературе.

## Оценка выигрыша (с чарджем)

- x-ray/mr: **−3…−8% self** поверх текущего MED16-пути (грубо, лит-якорь MRP vs CALIC/JPEG-LS на grayscale/медицине). На x-ray это напрямую расширяет тонкий image-margin −4.6% → ~−9…−13%, застраховывая нишу.
- Чардж: коэффициенты K×опора (fixed-point, ~K·L·2 байта) + карта назначения M групп + 1 profile-байт. Кодер медленный (итеративная rate-оптимизация, ×5–20 к текущему image-проходу), **декодер быстрый** (линейная свёртка + лукап группы на пиксель) — годится для rail (encode-time не в инвариантах).

## Отличие от H-* / FH-* / FH2-*

- **H-39/H-60/H-63 (MED/MED16)** и **H-59 (Paeth)** — ОДИН фиксированный предиктор; MRP — **набор предикторов с rate-оптимизированными, передаваемыми коэффициентами** (подгонка формы предиктора под файл, а не выбор из готовых). Принципиально иной механизм: оптимизируется САМ предиктор, не выбор.
- **FH-14 (CALIC-класс)** — фиксированный GAP + контекст-бакеты остатков; MRP оптимизирует линейные веса под rate (CALIC этого не делает).
- **FH2-09 (JPEG XL MA-tree)** — обучаемая структура КОНТЕКСТОВ (дерево свойств), фиксированные предсказания в листьях; MRP — обучаемые ПРЕДИКТОРЫ (веса свёртки). Ортогонально и потенциально стекается (MA-дерево выбирает MRP-группу).
- Передача коэффициентов ≠ закрытая φ-ветка (Gotcha #7): это МОДЕЛЬ (десятки байт весов), не перестановка данных; чардж включён в пробу.
