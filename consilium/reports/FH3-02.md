# FH3-02 — Bit-plane MSB/LSB декомпозиция 16-битного изображения с кросс-плоскостным контекстом (структурная MSB-плоскость + near-random LSB) — target: image (x-ray/mr 16-бит медицинские)

**Волна:** WAVE 3 (2026-07-22, Fable 5). **Статус:** PROPOSED, не запускалось.

## Механизм

16-битный медицинский grayscale разбивается по **битовым плоскостям** на старший под-объём (MSB-планы, несут анатомическую структуру, сильно предсказуемы 2D-контекстом соседей) и младший (LSB-планы, near-random шум сенсора, ≈несжимаемы — bitpack). Ключ SOTA-версии (BD-LVIC, CVPR-класс bit-plane slicing): **LSB-планы кодируются УСЛОВНО по уже декодированным MSB-планам** — кросс-плоскостной контекст ловит остаточную зависимость шум↔структура, которую единый 16-битный предиктор смешивает.

Перенос в Cubrim: после MED16-предсказания остаток раскладывается на sign/MSB-magnitude (контекст-модель по 2D-соседям остатка) и LSB-хвост (bitpack или лёгкий order-0). Каждая плоскость — отдельная ветвь кодера, каждый разрез чарджится. Всё целочисленно, детерминированно, fail-closed, за competitive-min.

## Чем берёт лидера

ppmd 0.4545 на x-ray. Наш MED16 предсказывает полный 16-битный отсчёт, но **энтропийный хвост остатка на 16-бит медицине — это в основном сенсорный шум в младших битах**, который единая контекст-модель обрабатывает по тем же контекстам, что и структурные старшие биты, размывая статистику. Явное разделение: сильная модель тратится ТОЛЬКО на предсказуемую MSB-структуру, а на near-random LSB не расходуется контекстная ёмкость и не платится штраф за ложную предсказуемость. Кросс-плоскостной conditioning ловит корреляцию, которую и MED16, и ppmd теряют.

## Научный источник (2024–2026)

- **«Learned Lossless Image Compression based on Bit Plane Slicing» (Zhang et al., CVPR 2024; ArIB-BPS)** — разрезание по битовым плоскостям с dimension-tailored авторегрессией; плоскости упорядочены по важности латентов.
- **«Learning Lossless Compression for High Bit-Depth Volumetric Medical Image» (BD-LVIC, arXiv 2410.17814, 2024)** — прямо для high-bit-depth медицинских объёмов: разбиение на MSBV/LSBV + parallel autoregressive coding LSB, обусловленный MSB. Класс наших mr/x-ray.
- **«Towards Lossless INR via Bit Plane Decomposition» (arXiv 2502.21001, 2025)** — bit-plane для 16-бит сигналов.

## Оценка выигрыша (с чарджем)

- x-ray/mr: **−2…−6% self** поверх MED16 (грубо; лит. BD-LVIC отчитывает заметный выигрыш над JPEG-XL на high-bit-depth медицине, но большая часть их разрыва — нейросетевой предиктор; здесь берётся ТОЛЬКО дешёвая структурная часть — разделение плоскостей + кросс-conditioning без нейросети). Честно: если LSB нашего остатка уже ≈max-энтропия (сенсорный шум), выигрыш = только устранение ложной предсказуемости в единой модели, может быть ближе к −1…−3%.
- Чардж: 1 profile-байт + разделительная логика (нулевой wire-overhead — разрез детерминирован). Кодер ×1.3–2, декодер ×1.3 (две ветви вместо одной).

## Cheap probe (GO/NO-GO)

1. **Минуты, измерение:** посчитать order-0 энтропию младших N бит остатка MED16 на x-ray/mr для N=1..8. Если LSB уже ≈N бит/пиксель (чистый шум) И условная энтропия LSB|MSB-контекст ≈ безусловной → кросс-conditioning не даёт ничего, NO-GO. Если H(LSB|MSB) заметно < H(LSB) → есть что брать, GO.
2. **День, Python:** разложить остаток на MSB-magnitude + LSB, кодировать MSB контекст-моделью по 2D-соседям, LSB — order-0/bitpack; end-to-end vs единый 16-битный кодер, с чарджем обеих ветвей.

## Риск / стоимость

- 2–4 дня. Арх-риск низкий (разделение потока, оба конца детерминированы). RT-риск низкий (competitive-min + fail-closed). Приоритет: **высокий в image-ветке** после/параллельно FH3-01; probe-1 (энтропия LSB) — одна из самых дешёвых во всей волне.

## Отличие от H-* / FH-* / FH2-*

- **H-50 (ALP-RD MSB/LSB для float)** — NO-GO, но это **float64 через байтовый backend** (sub-byte separation проиграла байтовой модели). Здесь — **16-битные integer-остатки после MED16-предсказания** с кросс-плоскостным conditioning; принципиально иной домен и наличие детерминированного предиктора перед разрезом.
- **H-60/H-63 (MED16)** — предиктор без разделения плоскостей; FH3-02 — что делать с остатком ПОСЛЕ MED16.
- **FH2-09 (MA-tree)** — структура контекстов; здесь — структура ПОТОКА (MSB/LSB split + conditioning). Ортогонально.
- **FH-13 (JBIG bilevel)** — одна битовая плоскость 1-битного факса; здесь — 16 плоскостей 16-битного grayscale с межплоскостной моделью.
