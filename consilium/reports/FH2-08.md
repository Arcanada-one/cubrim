# FH2-08 — Классовые словные контексты через вшитую кластер-таблицу (word-class LM, низкая кардинальность) — target: text vs PPMd (dickens/enwik8), запас на code

**Волна:** WAVE 2 (2026-07-21, Fable 5). **Статус:** PROPOSED, не запускалось.

## Механизм

Оффлайн кластеризовать ~32–64K частых английских слов в **256 (и 1024) семантико-синтаксических классов** (Brown-кластеризация / k-means по эмбеддингам — только оффлайн, в кодек попадает готовая таблица слово→класс, ~100–300 КБ, вшита в бинарь, wire = 0). В CM добавить контексты:

1. (класс предыдущего слова) — 256 значений;
2. (класс предыдущего, класс пред-предыдущего) — 64K значений;
3. (класс предыдущего слова, первые буквы текущего) — смешанный.

OOV-слова → класс по суффиксу/капитализации (детерминированное правило).

**Ключевое свойство — прямой ответ на урок FH-01/Gotcha #9:** словные order-2 контексты (FH-02) имеют кардинальность ~10⁹ и платят непосильный learning cost; классовые — 256–64K ячеек, наполняются за первые сотни КБ файла. Это способ дать CM «грамматику» БЕЗ высококардинальных таблиц.

## Чем берёт лидера

PPMd видит только байтовые суффиксы: после «the quick brown » он ничего не знает о том, что дальше вероятно существительное. Класс-контекст даёт p(«fox»|NOUN-slot) через статистику ВСЕХ пар (ADJ→NOUN) в файле — обобщение, структурно недоступное и PPMd, и нашим текущим байтовым/словным хэшам.

## Научный источник (2020–2026)

- **fx2-cmix** (Hutter Prize, сентябрь 2024): выигрышные NLP-компоненты — стемминг с «новыми типами слов», компактные словопотоки — свежее доказательство, что лингвистическая типизация слов двигает призовой бенчмарк.
- **L3TC** (AAAI-25): ограниченный словарь, покрывающий частые токены + outlier-bypass — тот же принцип «малый алфавит классов вместо гигантского словаря», у нас — на уровне контекстов, а не токенизации.
- Классовые LM (Brown clustering) — классика, возрождённая в 2020-х дешёвыми эмбеддингами; честная пометка: идея старая, свежесть — в комбинации с CM и в анти-Gotcha-#9 обосновании.

## Оценка выигрыша (с чарджем)

- Грубая, лит-якорная (вклад словно-грамматических моделей в paq8hp/cmix-классе на английском): **−1.5…−3.5% на dickens/enwik8/alice-классе прозы**; на webster (словарная структура) меньше; на не-английском (reymont) ≈ 0 (классы не матчатся, микшер занулит).
- Чардж: wire = 0; бинарь +100–300 КБ; скорость −5–10% (лукап класса — O(1) хэш на границе слова).

## Отличие от H-* / FH-*

- **FH-02** — ТОЧНЫЕ словные контексты (хэш конкретных слов, стем = последние 3 буквы): высокая кардинальность, учится только на повторах тех же слов. FH2-08 — **обобщающие КЛАССЫ** (высокая частота наполнения, перенос статистики между словами одного класса) + вшитая внешняя таблица. Механизм и профиль риска (Gotcha #9) противоположные.
- **FH-03 (WRT)** — трансформация ПОТОКА (замена слов токенами); здесь поток не меняется, добавляется контекст. Совместимы.
- **FH-06** — прайминг существующих счётчиков; здесь новые контексты со своей таблицей соответствия.
- В H-31..H-65 словных/классовых моделей нет.
