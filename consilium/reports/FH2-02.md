# FH2-02 — ∞-gram: неограниченный порядок контекста через онлайн суффиксный автомат как вход CM — target: text (webster/enwik8) + database (nci) vs PPMd/xz

**Волна:** WAVE 2 (2026-07-21, Fable 5). **Статус:** PROPOSED, не запускалось.

## Механизм

Онлайн строить **суффиксный автомат** (или укороченное суффиксное дерево) по уже раскодированному префиксу файла (детерминированно, O(1) амортизированно на байт) и на каждой позиции получать:

1. **Точную длину L самого длинного контекста**, встречавшегося ранее (неограниченный порядок — не 6, не 16, а сколько есть в данных);
2. **Точные счётчики продолжений** этого контекста (какие байты и сколько раз следовали за ним).

Из (1)+(2) формируется вероятностный вход микшера (частоты продолжений с KT-сглаживанием) плюс **селектор микшера по квантованной L** (доверие растёт с длиной подтверждённого контекста). Wire = 0, всё выводится из данных симметрично у кодера и декодера.

## Чем берёт лидера

- PPMd ограничен order-4..6 и платит escape-цепочку; ∞-gram даёт точную статистику контекста ЛЮБОЙ длины — на файлах с гигантской повторностью (webster: повторяющиеся словарные статьи; nci: молекулярные таблицы; enwik8: wiki-разметка) длинные подтверждённые контексты почти детерминированы.
- xz держит nci 64-МБ окном; суффиксный автомат — это «окно всего файла» с вероятностной (fractional-bit) оплатой вместо жёстких match-токенов.

## Научный источник (2020–2026)

- **Infini-gram: Scaling Unbounded n-gram Language Models to a Trillion Tokens** (Liu et al., arXiv 2401.17377, 2024): ∞-gram LM на суффиксных массивах, 47% точности next-token предсказания чистой статистикой, миллисекундные запросы; показал, что неограниченный порядок — практичный и сильный предиктор. Мы переносим идею в онлайн/потоковую форму (суффиксный автомат вместо статического суффиксного массива).
- Линия PPM* (unbounded PPM) — классика, но именно infini-gram (2024) дал свежее измеренное свидетельство силы неограниченного порядка на больших данных.

## Оценка выигрыша (с чарджем)

- Грубая, лит-якорная: на файлах с длинноповторной структурой **−3…−8% self-gain (nci, webster, samba)**, **−1…−2% на прозе** (dickens — повторов меньше). nci нужно −10.7% до xz — вместе с FH-15 (персистентный match) реалистично закрыть большую часть; webster нужно −7.8% до ppmd.
- Чардж: wire = 0. Память — главный ценник: суффиксный автомат ≈ 20–40 Б/байт → на webster 41.5 МБ это 0.8–1.7 ГБ; смягчение — скользящее окно автомата (например, 16–64 МБ) или суффиксный автомат по блоку с наследованием. Скорость: O(1)/байт с большими константами, оценочно −30–50% скорости CM.

## Cheap probe (GO/NO-GO)

**Часы, Python, без Rust:** суффиксный автомат (готовые ~100-строчные реализации) по dickens[:2MiB] / nci[:4MiB] / webster[:4MiB]; на каждом байте — реальный адаптивный log-loss предиктора (счётчики продолжений + KT), логистическая смесь с order-2 baseline. GO если смесь лучше baseline ≥1.5% на nci/webster И не хуже на dickens. Это честный online-замер (Gotcha #9): у ∞-gram контекстов число ЯЧЕЕК растёт с данными, но каждый использованный контекст по построению уже встречался — learning cost минимален (это его структурное преимущество перед хэш-контекстами высокого порядка).

## Риск / стоимость

- Реализация: 3–5 дней (автомат + инкрементальные счётчики + интеграция входа). Арх-риск средний (память!), RT-риск низкий (модель, не transform).
- Риск пересечения выигрыша с match-моделью (FH-04) и LZP (FH-15): часть повторов уже ловится; пробу делать ПОВЕРХ включённой match-модели (в смеси), а не против голого order-2 — иначе оценка завышена. В probe-протокол включить обе конфигурации.

## Отличие от H-* / FH-*

- FH-04 (match 2.0) — **хэш-эвристика с одним кандидатом** (2 указателя, вероятность через длину); здесь — **точная статистика всех продолжений** неограниченного контекста (частотное распределение, не единственный предсказанный байт) + гарантия отсутствия ложных матчей.
- FH-15 (LZP/persistent) — wire-механика пропуска повторов; здесь — вероятностная модель без флагов.
- H-45-CTW (PLANNED, закрыт как абстракция) — CTW взвешивает деревья фикс. глубины; ∞-gram — точные счётчики переменной глубины, другой механизм и другой источник.
- В логе суффиксных структур как предикторов нет нигде.
