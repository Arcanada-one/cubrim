Cubrim Web Profile — decoding application/cubrim in the page

This page fetches each asset as application/cubrim, decodes it in WebAssembly with cubrimDecode(), and then uses the result: the stylesheet below is applied from decoded bytes, the JSON is parsed, and the font is loaded from a decoded ArrayBuffer. Nothing here touches the browser's own content negotiation — it is an ordinary page calling an ordinary function.
