Cubrim Web Codec

Content-Encoding: cbm is an initiative exploring Cubrim for web content delivery. This section publishes only confirmed status and a high-level plan; technical details follow a separate review.

Roadmap

Stage 1. Cubrim Web Benchmark

Pending

Measure the current codec on a separate representative web corpus before making any performance claim.

Stage 2. WASM PoC

Pending

Build and validate a browser-side decoding prototype after the Web Profile contract is defined.

Stage 3. cubrimd reverse proxy

Pending

Prepare a server-side integration prototype with a safe fallback to standard delivery.

Stage 4. Chromium Technology Preview

Pending

Prepare an opt-in browser integration for controlled evaluation.

Stage 5. Specification and IETF

Pending

Prepare public specification and standards work only after technical validation and legal clearance.
